# Telegram и VK

Подключаются Telegram `@warehousecontourbot` и сообщество VK `warehouse_contour` (239116063). WhatsApp не отображается на странице входа и исключён из каналов доставки по умолчанию.

## Вход арендатора

Обычный вход содержит только телефон и код. Первичная настройка открывается по ссылке «Впервые здесь? → Подключить мессенджер»: на отдельном экране находятся фирменные кнопки и инструкции. Возврат сохраняет введённый телефон. В кабинете и карточках пользователей подключение свёрнуто по умолчанию.

1. Telegram: откройте бота, нажмите «Поделиться телефоном». Бот принимает только собственный контакт отправителя в личном чате. Телефон должен совпадать с карточкой пользователя.
2. VK: в кабинете откройте «Подключение мессенджеров», получите код для VK и отправьте боту всю команду `/link …`. Для первого входа администратор выдаёт эту команду в разделе «Пользователи» → нужная карточка → «Подключение мессенджеров».
3. Вернитесь на страницу входа, введите телефон и запросите код. Код приходит в привязанный Telegram и/или VK; после проверки используется один раз.

Одноразовая команда привязки действует 15 минут, в базе сохраняется только её хеш. Новый код отменяет предыдущий для того же пользователя и канала. Изменение телефона или блокировка отменяют возможность использовать старую привязку. Нельзя подключить чужой аккаунт, просто отправив боту его телефон текстом. Для Telegram также доступен `/link`.

Управляющий выдаёт команды только своим исполнителям; администратор — всем пользователям. Команду нужно передавать конкретному пользователю по проверенному каналу, не публиковать.

## Сервер

Токены и секреты — в `/opt/wirehouse/.env` и приватном `/opt/wirehouse/bots.env`, права 600. `pass.txt` исключён из Git. Webhook продолжают использовать API на `wirehouse.92.118.115.96.nip.io`; браузерный интерфейс опубликован на чистом origin `sklad-kontur.92.118.115.96.nip.io`.

- Telegram webhook: `/api/integrations/telegram/webhook`, проверяется `X-Telegram-Bot-Api-Secret-Token`.
- VK Callback API: `/api/integrations/vk/webhook`, проверяются secret и group_id, включая запрос подтверждения.
- `OTP_DELIVERY_CHANNELS=telegram,vk`; фиксированного кода входа нет.
- `GET /api/auth/tenant/onboarding` сообщает доступные каналы и публичные ссылки. Ключей в ответе и клиентской сборке нет.
- `POST /api/integrations/link-code` требует авторизации и проверяет область доступа.

Для изменения ключей обновить приватное окружение, пересоздать только `wirehouse-api`, затем зарегистрировать webhook с соответствующим секретом. Окружение и настройки webhook должны соответствовать опубликованной версии.

На 16.09.2026 адрес Telegram, полученный через DNS (`149.154.166.110`), недоступен с хоста. Для одного контейнера API используется `/opt/wirehouse/compose.network.yml` с `extra_hosts: ["api.telegram.org:149.154.167.220"]`; HTTPS продолжает проверять сертификат `api.telegram.org`. Скрипт обновления учитывает этот необязательный файл при запуске. Для ручного пересоздания: `docker compose -p wirehouse -f compose.yml -f compose.network.yml up -d api`. Это временная маршрутизация: при восстановлении обычного доступа удалить файл и пересоздать API; при изменении доступности адреса повторно проверить маршрут и сертификат. DNS остальных контейнеров и хоста не менялся.

Оба webhook зарегистрированы на текущем домене: Telegram без ожидающих обновлений и ошибок, VK — `status=ok`. Доступность API провайдеров и действительность токенов проверены из рабочего контейнера, без отправки сообщений пользователям.

## Проверки и источники

`tests/bot-links.test.mjs` проверяет собственный контакт, права на выдачу команд, срок/однократность, блокировку, секреты webhook, обе доставки OTP и вход. В тестах внешние провайдеры заменены локальным транспортом: сообщения реальным людям не отправляются.

Браузерный тест проверяет логотипы, фирменные цвета, отсутствие WhatsApp, мобильный экран 320 px и выдачу команды из карточки пользователя.

Документация: [Telegram Bot API](https://core.telegram.org/bots/api), [официальная схема VK API](https://github.com/VKCOM/vk-api-schema/blob/master/groups/methods.json).

# Фоновое обновление без скачков — 29 октября 2026

При повторных запросах `useResource` показывал строку «Загружаем данные…», а серверные реестры заменяли уже загруженную таблицу заглушкой. Это меняло высоту страницы. Теперь загрузка отображается только до первого ответа для текущего ключа запроса. Фоновые обновления сохраняют строки и положение содержимого. Смена фильтра или страницы по-прежнему использует отдельный ключ: предыдущая выдача не подставляется под новые условия. Ошибки и отзывы доступа обрабатываются прежним QueryClient; закрытые данные не сохраняются после 401/403/404.

В чате наличие одного ещё не загруженного списка комментариев ставило весь диалог в состояние загрузки. Теперь выводятся уже доступные сообщения текущих заявок; остальные добавляются по мере ответа. Пустые/неразрешённые снимки не подставляют данные другого диалога. Менеджер и арендатор показывают заглушку только при отсутствии сообщений для отображения.

Проверка: `npm run check` (TypeScript, обычные тесты и web build). Адресный браузерный прогон с фактическими GET-ответами production и локальными фикстурами WebSocket/задержки/добавляемой заявки и комментариев подтвердил: во время задержанного обновления таблица остаётся видимой, координата заголовка не меняется, строка загрузки не появляется; добавленная загружающаяся заявка не скрывает сообщения и не стирает черновик; новый комментарий появляется после обновления. Фикстуры не записываются в production. Приватные результаты: `.local/refresh-stability-20261029/`.

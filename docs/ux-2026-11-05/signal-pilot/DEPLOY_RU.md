## Обнаруженные и устранённые проблемы выпуска

До загрузки проверка остановилась из-за изменений соседнего Sloppy относительно вчерашнего baseline. Два новых read-only снимка подтвердили, что различаются только три пересозданных и четыре добавленных контейнера Sloppy и его nginx-файл. Все остальные контейнеры, конфигурации Wirehouse, API, 16 SQL-checksum, assets и downloads совпали. Новый baseline принят после независимой проверки; проверки перед загрузкой и перед переключением сохранены.

Серверная публикация завершилась с первой попытки. После неё локальная команда завершилась ошибкой: PowerShell перенаправил вывод в тот же `production-deploy.log`, который помощник записывает самостоятельно. Успешный серверный результат восстановлен точным read-only чтением исходных `state.json` и `result.json`; затем прошёл полный postflight. Повторной активации, загрузки, миграции или восстановления БД не было. Исходный локальный ошибочный лог сохранён приватно.

GitHub CI исходного коммита прошёл установку, `npm run check` и PostgreSQL-проверки, но остановился в старом браузерном сценарии: он искал кнопку «По телефону», хотя переключатель уже имел роль `tab` до нового дизайна. Результат актуализации этой обвязки фиксируется отдельным тестовым коммитом; опубликованные файлы приложения от неё не меняются.

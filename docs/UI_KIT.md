# UI kit

Интерфейс рассчитан на ежедневную работу управляющего недвижимостью: плотные данные, понятные действия, минимум декоративного текста. Страницы используют название раздела; пояснение добавляется только для неочевидного действия или ограничения.

Токены в `apps/web/src/ui/ui.css`: фон #F5F7FA, поверхность #FFFFFF, текст #182533, вторичный текст #566575, граница #D6DDE4, действие #176B5B. Основной шрифт системный; данные используют табличные цифры, команды — моноширинный шрифт. Поле/кнопка от 44 px, радиус контролов 6 px, карточек 8 px; отступы 4/8/12/16/24 px. Telegram и VK сохраняют фирменные цвета.

- `Button`: primary — главное действие, secondary — дополнительное, danger — удаление/опасная операция, text — переход, plain — элемент навигации со своим макетом. По умолчанию `type=button`; отправка формы требует явного `type=submit`. Busy блокирует повторное действие.
- `Input`, `Select`, `Textarea`: единая геометрия, видимый фокус и ошибки; мобильный текст полей 16 px. Checkbox имеет свой размер и кликабельную подпись.
- `Field`: подпись связывается с контролом, hint/error через aria-describedby.
- `Alert`: ошибка — role=alert, успех — role=status; текст объясняет действие пользователя.
- `Badge`, `PageHeader`, `Card`, `EmptyState`: состояния, заголовки и пустые выборки.

Основная мобильная навигация — бургер. Таблицы превращаются в карточки через ResponsiveTable; контент и действия переносятся внутри доступной ширины. Проверяем 320/360/390/768/1024 px, сохранение данных при возврате, фокус, отсутствие горизонтального переполнения. Дополнительные настройки и подключение мессенджеров раскрываются только по запросу пользователя.

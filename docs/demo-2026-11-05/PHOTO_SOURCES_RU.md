# Фотографии счётчиков для учебного показа

Обе фотографии взяты из Wikimedia Commons. Это реальные фотографии сторонних приборов для помеченного учебного набора; они не являются фотографиями нашего объекта. Цифры не изменялись. В пакете сохранены официальные уменьшенные копии Commons по960px; авторские изменения оригиналов смотрите на страницах источника.

## Механический водосчётчик Minol

Файл: [Фото счётчика — 226.492.jpg](Фото%20счётчика%20—%20226.492.jpg). Видимое значение: **226.492 м³**.

Автор: Bin im Garten. [Источник](https://commons.wikimedia.org/wiki/File:Haushaltswaserz%C3%A4hler_warm_und_kalt_PD_1.JPG). [Лицензия CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

# Склад Контур

Управление складской недвижимостью: помещения, арендаторы, договоры, начисления, заявки и эксплуатация. Браузерный интерфейс с кабинетами управляющего, исполнителя и арендатора; Telegram и VK для привязки и кодов входа.

## Разработка

Требуется Node.js **24.11+** и npm. Node выполняет серверный JavaScript и общие TypeScript-схемы без отдельного серверного транспилятора.

```sh
npm ci --ignore-scripts
cp .env.example .env
npm run dev:api
npm run dev:web
```

Локальная база по умолчанию — JSON в `apps/api/data/`. Для демонстрационных данных используйте `.env.demo.example` вместо `.env.example`. Это отдельный режим разработки; production запрещает демонстрационное заполнение, фиксированный OTP и вход без доставки. Реальные ключи в Git не добавляются.

```sh
npm run check                  # типы, доменные/API-тесты, production-сборка web
npx playwright install chromium
npm run test:browser           # изолированные данные; без сообщений реальным пользователям
```

GitHub Actions запускает обе проверки. Дополнительные оболочки Android и Windows находятся в `apps/`; для запуска Electron после установки с `--ignore-scripts` выполните `npm rebuild electron`.

## Состав

- `apps/web/src/app` — каркас, контекст авторизованного кабинета и обработка ошибок.
- `apps/web/src/features` — страницы и компоненты по функциям; страницы загружаются по мере открытия.
- `apps/web/src/state` — состояние, вычисляемые представления, эффекты и действия по функциям.
- `apps/web/src/ui` — общие контролы и дизайн-токены.
- `apps/api/src/routes` — HTTP-маршруты по предметным областям.
- `apps/api/src/services` — выборки, доставка, боты, документы и импорт/экспорт.
- `packages/contracts/src` — строгие схемы запросов и общие DTO ответов.
- `tests` — автоматические проверки; `infra/deploy` — актуальное развёртывание и резервные копии.

# Склад Контур

Мобильный выпуск: [0.4.0 · 12 ноября 2026](docs/RELEASE_2026-11-12_MOBILE_0_4_0.md).

Управление складской недвижимостью: помещения, арендаторы, договоры, начисления, заявки и эксплуатация. Браузерный интерфейс с кабинетами управляющего, исполнителя и арендатора; Telegram и VK для привязки и кодов входа.

Интеграция с 1С: [расширение и агент обмена](integrations/one-c/README.md), [проверенный сценарий демонстрации с показаниями и документами](docs/demo-2026-11-06/RELEASE_RU.md). История первоначального обследования — в [отчете 22.10](docs/ONE_C_RELEASE_2026-10-22.md). Мобильный выпуск 0.4.0 обновляет сервер до схемы 18; расширение и агент 1С в нём не меняются. Проверки нового сеанса обмена с работающей 1С в этот мобильный выпуск не входят.

## Разработка

Требуется Node.js **24.11+** и npm. Node выполняет серверный JavaScript и общие TypeScript-схемы без отдельного серверного транспилятора.

```sh
npm ci --ignore-scripts
cp .env.example .env
npm run dev:api
npm run dev:web
```

API всегда использует PostgreSQL. После настройки `DATABASE_URL` выполните `npm run db:migrate`. Для новой пустой установки создайте первого администратора командой `npm run db:create-admin` с переменными `INITIAL_ADMIN_NAME`, `INITIAL_ADMIN_EMAIL` и `INITIAL_ADMIN_PASSWORD`. Тестовые данные автоматически не создаются.

```sh
npm run check                  # типы, доменные/API-тесты, production-сборка web
npx playwright install chromium
npm run test:browser           # изолированные данные; без сообщений реальным пользователям
```

Инструкции по схеме, обновлению и резервным копиям: [DATABASE.md](docs/DATABASE.md).

`TEST_POSTGRES_URL` включает проверки API и браузера на отдельных временных базах. `npm run test:postgres` проверяет миграции, ограничения и параллельную работу двух API; пользователь тестовой БД должен иметь право `CREATE DATABASE`. Мобильное приложение для Android и iOS — `apps/mobile` ([сборка](apps/mobile/README.md), [решения и выкладка](docs/MOBILE_APP_2026-11-09.md)); оболочка Windows — `apps/desktop-windows`, для запуска Electron после установки с `--ignore-scripts` выполните `npm rebuild electron`.

## Состав

- `apps/web/src/app` — каркас, контекст авторизованного кабинета и обработка ошибок.
- `apps/web/src/features` — страницы и компоненты по функциям; страницы загружаются по мере открытия.
- `apps/web/src/state` — состояние, вычисляемые представления, эффекты и действия по функциям.
- `apps/web/src/ui` — общие контролы и дизайн-токены.
- `apps/api/src/routes` — HTTP-маршруты по предметным областям.
- `apps/api/src/persistence` — SQL-миграции, пул соединений, транзакции и хранение записей.
- `apps/api/src/services` — выборки, доставка, боты, документы и импорт/экспорт.
- `packages/contracts/src` — строгие схемы запросов и общие DTO ответов.
- `tests` — автоматические проверки; `infra/deploy` — актуальное развёртывание и резервные копии.

# Бланки документов — 6 ноября 2026

В каталоге 14 незаполненных форм, каждая в редактируемом DOCX и в PDF для просмотра и печати. PDF получены штатным экспортом Microsoft Word 16.0 из тех же DOCX. HTML под расширениями PDF/DOCX, изображения вместо текста, макросы и выдуманные подписи не используются.

## Применение

| Бланк | Где использовать |
| --- | --- |
| Договор аренды нежилого помещения | Договор, помещение, объект |
| Дополнительное соглашение | Изменение условий договора |
| Акт приёма-передачи помещения | Передача помещения, ключей и документации |
| Дефектная ведомость | Осмотр объекта, помещения, оборудования; заявка |
| Заявка на техническое обслуживание | Обращение и условия доступа |
| Наряд-задание | Назначение и фиксация работ |
| Смета работ и услуг | Согласование объёмов и стоимости |
| Акт выполненных работ / услуг | Приёмка результата, объёма и стоимости |
| Акт ввода / замены прибора | Установка, замена, показания, поверка и пломбы |
| Акт снятия показаний | Прибор, период, ЛС, значения и подтверждение |
| Акт сверки взаимных расчётов | Договор, ЛС и расхождения сторон |
| Счёт на оплату | Банковские реквизиты, позиции и сумма платежа |
| Карточка оборудования | Учётные и паспортные сведения, документация, ответственный |
| График ППР | Плановые даты, работы, периодичность и исполнители |

Договор аренды занимает два листа; остальные формы — по одному. График ППР — альбомный A4. Строки таблиц можно дополнять в DOCX.

## Оформление и нормативная основа

Действующий [ГОСТ Р 7.0.97-2025](https://protect.gost.ru/gost/details/360994e3-9a70-47b9-ab3a-cf21809e26ed) определяет оформление организационно-распорядительных документов; он введён 18.08.2025 взамен версии 2016 года. [Рекомендации Росархива 2026 года](https://archives.gov.ru/documents/methodics/met-rek-gost-7-0-97-2025.shtml) раскрывают его применение. Для этих бланков выбраны белый A4, поля 30/15/20/20 мм (левое/правое/верхнее/нижнее), Times New Roman 12 пт, интервал 1,15, отступ основного текста 1,25 см; таблицы и подписи — 10,5–11 пт. Продолжение многостраничного документа нумеруется в верхнем поле, первый лист — без номера.

Это собственные организационные формы с учётом правил оформления, **не утверждённые государством унифицированные формы**. ГОСТ не задаёт универсальный текст договора или акта. Конкретные условия договора, реквизиты, полномочия и применяемые формы утверждает организация до подписания. Для первичных документов предусмотрены поля для сведений о составителе, дате, содержании операции, натуральном/денежном измерении с единицами и подписантах; источник — [разъяснение ФНС к статье 9 Закона № 402-ФЗ](https://www.nalog.gov.ru/rn57/news/tax_doc_news/5341377/). Ссылка ФНС — архивное разъяснение состава реквизитов, а не источник текущих налоговых ставок: ставки и суммы оставлены пустыми.

Счёт на оплату не заменяет установленную налоговую форму счёта-фактуры или электронный УПД. Наряд-задание не заменяет специальный наряд-допуск. Карточка оборудования не заменяет паспорт изготовителя, протокол испытаний, сведения о поверке или инструкцию по безопасной эксплуатации: эти подлинные документы загружаются отдельно. Ни один бланк сам по себе не подтверждает выполненную работу, оплату или подпись.

## Файлы и проверка

`catalog.json` хранит применимые сущности, категории, форматы, размеры, число PDF-страниц, SHA256 и источники. API отдаёт только бланки из закрытого перечня и проверяет размер/хеш перед выдачей. Наличие бланка в каталоге не создаёт договор, акт или запись обмена в базе.

Генератор: `scripts/generate-document-templates.py --export-pdf`. Python и Word нужны только для авторской пересборки, в production API читает готовые файлы. Word запускается как отдельный скрытый экземпляр; существующие документы и процессы пользователя не используются.

Проверены все 28 файлов: DOCX открыты в Word, PDF отрендерены и визуально просмотрены; 15 страниц без пустых листов и выхода за границы. OpenXML ZIP/XML читаются, макросов и внешних связей нет. Частные журналы и контрольные рендеры хранятся в `.local/doc-templates-20261106/`.
